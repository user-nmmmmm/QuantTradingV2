## 2. MATIC 的 83 行和下架日

83 个接口未提供的日期恰为 **2025-01-01 至 2025-03-24**，其余匹配日期为
2019-04-26 至 2024-09-10。没有证据能够确定这 83 行的原始来源，也不能把它们自动更名为 POL。

Binance 公告明确 MATIC 现货交易对在 **2024-09-10 03:00 UTC（11:00 SGT）**停止交易，
POL 现货在 **2024-09-13 10:00 UTC（18:00 SGT）**开始。
1:1 代币兑换关系没有建立同一交易对和连续可执行日线的证明。
依据：[Binance MATIC→POL 迁移及现货下架公告](https://www.binance.com/en/support/announcement/detail/6a6de383727f4659a3050f7982e1620f)。

接口中的 2024-09-10 日线虽然与本地一致，覆盖的交易日受 03:00 UTC 下架影响，
不能直接当作完整日终可执行行情。保守候选因此额外排除这 1 行：
**83 行来源缺口 + 1 行交易生命周期边界，共移出 84 行，保留 1964 行**。
这是待批准的使用边界，不把匹配的下架日归成第 84 行“数据不一致”。
原文件仍留存；若保留到下架日研究，需另行定义停止交易、退出持仓及缺失时段的处理。

## 5. 离线复核

需要含原始输入提交的完整 Git 历史；浅克隆须先补齐该提交。已安装项目后，在仓库根目录运行：

```powershell
python scripts/dev.py data-review
python -m pytest -q tests/test_data_adoption_review.py tests/test_data_input_integrity.py
```

校验器从 review 指定的 Git 提交读取输入，不使用未来被采用变更替换的工作区文件冒充旧输入。
它拒绝摘要/文件集合漂移、旧比较策略、无效末根见证和不一致的计数；未知的 mismatch 留在待审隔离状态。
`--write-draft` 只能新建 JSON，拒绝覆盖既有文件，不写 CSV 或正式采用回执。
采用草案字段被修改为“已批准/已采用”，或候选摘要被改写，`--check` 均失败。
