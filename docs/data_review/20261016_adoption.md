## 研究入口如何执行上限

`data/binance/1d/_research_policy.json` 由回执确定，绑定回执摘要、每份 CSV 的 LF 规范化摘要及日期上限。
`cli.data.get_data(..., source="local")`（含命令行回测及调用该入口的工作台路径）
在读取前拒绝超出上限的结束日期、未登记文件和错误周期；按同一字节快照解析 CSV 并验证摘要。
启用 `DataVersionStore` 也使用快照内的同一字节核验，不能绕过边界。

```powershell
python main.py --source local --data-dir data/binance/1d --symbols BTC/USDT --start 2020-01-01 --end 2026-08-26
```

`--end` 超出本次上限会明确报错，不悄悄把请求截短后继续标成较晚窗口。
MATIC 请求的 `--end` 必须不晚于 2024-09-09。独立脚本直接读取 CSV 时，也必须按回执显式限定窗口；
保留的 BTC/ETH 下载尾部不允许用于扩大本次采用研究的结束日期。历史冻结回放继续使用自己的旧输入和协议。
