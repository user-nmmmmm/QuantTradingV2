## 冻结依据

问题台账（「问题清单」sheet）中已记录的 P0 级问题涵盖业绩可信度、生命周期、成本会计、保证金/杠杆、可复现性、样本外验证等多个维度，包括但不限于：

- I-01 低收益、高回撤、低 Sharpe 且严重跑输基准
- I-05 策略闭合回调覆盖率仅 60.5%（生命周期未闭环）
- I-15 / I-16 报告未保存 Git SHA、完整配置、seed、数据哈希（不可复现）
- I-23 资金规模变化（10k vs 1m）导致交易路径与收益方向不同
- I-25 成本敏感性重复扣滑点
- I-29 无初始/维持保证金与强平机制
- I-38 未冻结最终样本外测试集
- **I-42 当前结果不满足实盘准入条件**（可信度、策略、成本、风控同时存在 P0 问题）

对应「验收门槛」Gate G0（基线冻结）：五组回测、代码和配置均已具备只读归档与哈希（T-0.1～T-0.3 完成），Gate 状态更新为「通过」；但这仅代表**基线已被冻结、可复现追溯**，并不代表策略本身已通过后续 Gate（G1~G6）或具备实盘条件。

## 明确禁止事项

1. **禁止**将当前基线（或其任何回测结果）作为实盘交易的依据或参考业绩展示。
2. **禁止**基于当前基线结果进行资金扩容、加杠杆或新增策略上线决策。
3. **禁止**修改本目录（`docs/baseline/phase0/`）下已归档的只读文件；如需更新基线，须在 Phase 0 之外新建带日期戳的归档并保留旧版本。
4. 后续 Phase 1~6 的所有修复、验证工作必须以本基线为可复现起点（同一 commit + 配置 + 数据哈希应可重现归档中的回测结果）。

## 解冻条件

只有当 Gate G1~G6（生命周期覆盖、会计恒等式、成本基准一致、可复现性、审计产物完整、关键数据核验）以及 Phase 5/6 的样本外验证、多重检验修正均通过验收标准后，方可重新评估是否解除实盘冻结，并需由风控负责人与研究负责人共同签署确认。
