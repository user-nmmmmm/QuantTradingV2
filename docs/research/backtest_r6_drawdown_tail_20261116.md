## 1. 问题

1. 历史上那一条路径的最大回撤，只是一次抽样。同样的收益过程，换一种排列，最大回撤的分布是什么？
2. 回撤预算在这个分布下是否仍然守得住？恢复需要多久？
3. 保护性止损在跳空行情下，实际成交亏损与计划风险（R）相差多少？

H0：最大回撤的 95 分位不超过预算的 1.5 倍，且保护止损的 99 分位成交亏损不超过 2R。

## 2. 三个子研究

### 2.1 回撤分布（移动块自助法）

对象：S1、S2 在 train60 ∪ validation20 上、1× 成本下的**日度组合收益序列**（取自 R4 `c1.0` 的运行）。

- 移动块自助法，块长 {5, 10, 20}（5 为主，其余为敏感性），B = 10000 次，固定种子；
- 重采样长度：与样本等长，以及 252 与 504 个交易日的前瞻窗口；
- 输出：最大回撤 P50/P90/P95/P99、回撤持续天数、恢复天数分布、`P(最大回撤 > 预算)`。

回撤预算值在冻结时从配置读出（见 [`drawdown_budget`](../../backtest/drawdown_budget.py) 的约束），写入登记。

### 2.2 保护止损的跳空成交

回放 R4 `c1.0` 里实际触发保护止损（含初始止损与追踪止损）的全部成交：

- 对每笔计算 **R 倍数** = 实际亏损 / 开仓时计划风险；
- 成交价与止损价的差（跳空滑点），按"次日开盘穿过止损价"与"盘中触及"分类，口径沿用回测假设的止损单成交规则
  （卖出止损按 `min(Open, Stop)`）；
- 输出：R 倍数分布（P50/P95/P99/最大）、跳空占比、跳空笔的平均超额亏损。

### 2.3 回撤预算在历史路径上的触发

读取引擎记录的预算触发事件：触发次数、触发后的恢复、触发期间被禁开仓的 bar 数与错过的收益。
这是对历史路径的描述，不作显著性检验。

## 4. 预注册判定规则（草案阈值）

对象 X **通过**，当且仅当：

1. 块长 5、重采样长度 = 样本长度时，最大回撤 P95 ≤ 1.5 × 回撤预算；
2. `P(最大回撤 > 预算)` ≤ 10%；
3. 恢复天数的 P95 ≤ 样本长度的 1/3（草案，由所有者确认）；
4. 保护止损 R 倍数的 P99 ≤ 2.0；
5. 回撤预算触发后没有"无法恢复"的事件（触发后 252 个交易日内净值未恢复到触发前高点的比例 ≤ 10%）；
6. 块长 {10, 20} 的结论方向不反转（1、2 任一在敏感性下由通过变为不通过，则整体判"未通过"，并说明敏感度）；
7. 样本量：止损成交 ≥ 30 笔；否则 2.2 部分判"证据不足"，其余照常。

不满足 1–5 任一：**未通过**，并给出是回撤分布、恢复还是尾部成交造成的。

## 7. 已知局限

- 自助法重采样的是**收益序列**，不重跑引擎：策略的状态机、健康/冷却、预算触发都依赖路径，
  重采样会打断这些反馈，因此分布是对"同分布收益、无反馈"的近似，不是对策略完整行为的模拟。
- 日线最大回撤看不到日内回撤；保护止损的"盘中触及"成交价在日线下只能用止损价近似。
- 样本只覆盖少数几轮加密货币周期，P99 实质上由很少的极端日决定，应读作量级而不是精确数值。
- 历史上的最大回撤与回撤预算触发是同一条路径上的事件，不是独立样本。
