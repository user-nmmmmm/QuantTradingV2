# R2 滚动样本外（2026-11-16）

## 1. 问题

两个问题，必须分开回答：

1. **流程问题**：每个窗口只在验证段选参、在独立测试段评价，这套选参流程的样本外收益是否为正？
2. **增量问题**：调参是否优于不调参？也就是"滚动选参的拼接测试收益"是否优于"固定使用默认参数"的同期测试收益。

若第 2 个问题回答"否"，结论是"默认参数已足够，调参不增加价值"，而不是"策略失败"。

## 2. 候选集合

候选必须是零参工厂（健康与冷却状态不跨窗口泄漏）。网格在冻结时一次写死：

| 对象 | 维度 | 取值 |
| --- | --- | --- |
| S1 | `entry_window` × `exit_window`（`exit < entry`） | {10, 20, 40, 55} × {5, 10, 20}，保留 `use_obv=True` |
| S2 | `horizons` × `target_annual_volatility` | {(30,90), (60,120), (90,180)} × {0.08, 0.10, 0.15} |

固定默认候选（S1 为 20/10，S2 为 `(60,120)` 与 0.10）必须包含在网格内，并单独记录其每窗测试收益。
候选总数记入累计尝试数。

## 3. 窗口几何

日线，滚动（非扩展）为主，扩展窗口作敏感性：

| 参数 | 草案值 |
| --- | --- |
| `train_size` | 730 |
| `validation_size` | 180 |
| `test_size` | 90 |
| `purge_size` / `embargo_size` | 30 / 30 |
| `step` | 90（须 ≥ `test_size`，测试段不重叠） |
| `expanding` | False（主）；True（敏感性） |
| `selection_metric` | `SharpeRatio` |
| `bootstrap_samples` / `bootstrap_block_length` / `seed` / `fdr` | 2000 / 5 / 42 / 0.05 |
| `initial_capital` | 每窗重置，与配置一致 |

窗口数量由公共时间线决定，预热不足的窗口进入 `skipped_windows`，**不缩短预热**。
标的集合分两档，在冻结前先产出"标的上市日表"，并按下面规则写死：
*核心集* = 首根 bar 不晚于 2020-12-31 的标的（保证足够多的完整窗口）；*全集* = 全部标的，窗口只纳入当时已上市标的。
主结论用核心集，全集作稳健性对照。

## 4. 数据

窗口落在 train60 ∪ validation20 的时间范围内；final20 与其前 30 根 purge 区禁止读取。
这意味着测试段的整体范围不超过 validation20 的末端。

## 5. 指标

窗口级：测试段 `ratio`、夏普、收益、最大回撤；获选参数；获选者在该窗验证段的排名与测试段的排名。
汇总级：拼接测试收益（诊断用，**不代表连续实盘账户**，每窗资金重置）、正收益窗口占比、
获选参数的漂移（模式频率、相邻窗口参数的距离）、验证→测试的排名相关（衰减程度）。

## 6. 预注册判定规则（草案阈值）

对象 X **通过**，当且仅当：

1. **流程**：拼接测试夏普 > 0，且块自助法下限在 FDR 0.05 下 > 0；
2. 正收益测试窗占比 ≥ 55%；
3. **增量**：流程的拼接测试夏普 ≥ 固定默认候选的拼接测试夏普 − 0.1（容忍小于一个估计噪声的差；
   差大于 0.1 且为负，则判"调参有害"，结论为"默认参数优先"，对象状态仍可为"通过"但调参部分记"未通过"）；
4. 获选参数不过度漂移：同一参数在 ≥ 40% 的窗口里被选中，或所有被选参数的测试夏普中位数 > 0；
5. 样本量：有效（未跳过）窗口 ≥ 8；少于 8 则整体"证据不足"。

3 与 4 不满足时分别记录，不合并成一个分数。

## 9. 已知局限

- 每窗约 90 根测试 bar，S1 在单窗内交易数很少，窗口级结论噪声大；因此判定规则用拼接与占比，而不是单窗显著。
- 拼接收益把"每窗重置"的账户串起来，会忽略跨窗持仓；窗口尾部按引擎 terminal policy 估值，
  默认 `mark_to_market` 没有额外退出成本，相对强平口径偏乐观；敏感性中加跑一次强平口径。
- 验证段已被部分研究看过的污染问题见总纲第 2 节；R2 在滚动窗口内选参，污染只影响最后几个窗口，需在结果里标出这些窗口。
