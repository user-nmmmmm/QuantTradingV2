## 按预注册规则的判定

| 方案 | train60 | validation20 | 通过 |
| --- | --- | --- | --- |
| obv_off | ✓（收益/回撤与 top5 都更好） | ✓（0.032 > 0.004，−349 > −366） | **是** |
| stab2 | ✗ 收益/回撤 1.64、top5 为负 | top5 更差 | 否 |
| stab3 | ✗ 收益/回撤 1.65、top5 为负 | ✓ | 否 |
| stab10（对照） | ✓ | ✗ 回撤 12.77 超上限 9.99、收益/回撤为负、top5 更差 | 否 |

| cool1 | ✗ top5 更差（2691 < 2842） | ✗ 收益/回撤为负、top5 更差 | 否 |

- **结论**：OBV 维度唯一通过，`obv_off`（去掉 OBV 确认）成为阶段 C1 的入场维度候选；稳定期与路由冷却维持现状。
- **证据强度要说清楚**：validation20 的改善只有 +0.19 个百分点收益、+17 USDT 的 top5，形式上满足规则，
  实质上接近持平；train60 的改善（+7.3 个百分点）也只来自 3 笔交易的差别（145 → 142）。
  这是“去掉 OBV 不会变差”的证据，不是“OBV 有害”的有力证据。
- 稳定期两个方向都不稳定：放宽（2/3）在 train60 明显变差；收紧（10）在 train60 收益翻倍、在 validation20 亏损 10% 且回撤超限。
  说明该参数对结果影响很大且方向随分段改变，不应据此调参。
- SR-ALPHA-002（`use_obv`）由本研究给出结果；SR-ALPHA-003 只覆盖了 `stability_period` 维度，ADX 与 ATR 阈值未研究。

## 对阶段 C 的含义

C1 若采用 `obv_off`，必须作为**唯一**改动建立新候选身份与新前瞻观察窗，再走 SR5 单次保留段评价；
本研究不改 `config/params.yaml`。
