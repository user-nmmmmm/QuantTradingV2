# 订单批准风险契约修复与验证（2026-09-12）

本次修复将实际批准风险金额贯穿策略定仓、风险决定、风险预留、订单意图和成交后复核。
研究配置保持原有 `paused_revalidation`。本报告记录工程验证；不构成新的 60 币种收益验证或实盘准入证据。

## 契约

```text
approved_risk_amount = final_approved_qty * abs(sizing_reference_price - initial_stop)
actual_total_risk = cumulative_filled_qty * abs(cumulative_average_fill_price - order_initial_stop)
risk_budget = order.approved_risk_amount
```

预算以报价币计量，在账户、健康、仓位上限和组合分配缩放之后冻结。
`RiskDecision`、`RiskReservation` 和 `OrderIntent` 均携带该金额；实盘使用现有订单账本的 intent JSON 持久化。
交易所数量精度向下取整时，金额按数量比例缩小。后续权益或风险乘数改变不扩大旧订单预算。
订单业务 ID 不因新增预算字段改变。

回测保留开仓订单及其累计成交记录，按累计数量和均价复核。发生超限时撤销剩余开仓意图，
通过 `GapRiskResize` 减仓；保护单和其他退出不会被这次开仓撤销操作取消。
已成交或仍在途的减仓数量计入检查点，取消和拒绝后可以重试。

实盘检查点持久化累计成交数量、均价和已完成的累计减仓目标。旧版检查点首次读取时重新核验。
减仓自身分批成交并跨重启完成后，检查点记住已完成的整个目标，防止下一笔入场成交引发重复减仓。
已平仓订单不允许影响同币种后来的持仓。迟到成交测试覆盖权威成交事实写入账本后的处理，
没有扩大为对所有交易所迟到成交发现机制的验证。

旧订单缺少金额时，只能从原始 requested_qty、reference_price（或原 price）和 initial_stop 重建，
来源标记为 `legacy_order_reference`。显式无效金额禁止回退。持仓所需原始事实缺失时，实盘进入
DEGRADED、发出 `entry_risk_approval_missing`，阻止该 tick 的新风险并保留待核验状态。

## 复现与修复证据

| 场景 | 旧问题 | 新验证结果 |
|---|---|---|
| REDUCE 后跳空 | 批准 100、实际风险 150，被按基础预算 200 放过 | 按批准 100 判断超限并缩量 |
| 同一订单两次成交 | 5 单位成交于 100，后续 15 单位成交于 125，止损 90；同一 lot 跳过二次复核 | 累计风险 575 对预算 200，缩减约 13.043478 单位 |
| 多重定仓缩放 | 账户、健康及组合缩放可能在复核时丢失 | 最终批准 10 同时进入决定、预留和订单；后续状态恢复不放宽 |
| 实盘重启和新增部分成交 | 检查点可能漏核或重复下减仓单 | 持久预算复用，新增成交触发增量处理，重复检查不重复下单 |
| 减仓自身部分成交 | 重启后只记住当时剩余缩量，遗忘此前已完成部分 | 持久目标完成后记住累计目标；后续新成交只减新增超限部分 |
| 旧订单及非法预算 | 可能从当前权益制造预算，或影响新仓 | 只用原订单事实；缺失时阻止新风险；已关闭订单隔离 |
