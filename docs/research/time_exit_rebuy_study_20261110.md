# SR-EXIT-001 到期平仓后立即买回：发生次数与成本（2026-11-10）

> 状态：**已登记，结果产生之前冻结**。本文件与 `scripts/run_time_exit_rebuy_study.py`
> 的哈希写入 `reports/time_exit_rebuy_study_20261110/registration.json`；任何一项变化脚本都拒绝继续。
> 路线图：[策略整改 Roadmap](../strategy_remediation_roadmap_20261110.md) B4（问题 F-06）。

## 1. 问题

Router 的最长持仓期（`router.max_holding_days`，默认 365 天）到期后按收盘价全仓卖出。
卖出后标的变为空仓；如果价格仍在 20 日高点之上，`TrendBreakout` 下一根 bar 就可能再次产生入场信号，
等于付两次成本把同一笔仓位“续期”。F-06 只是设计推演，从未量化。

**污染声明**：登记前没有查看任何运行中的到期平仓记录。本研究只计数和计成本，不选参数。

## 2. 方法

- 冻结输入：`reports/strategy_review_20260919/frozen_inputs`（60 币 Binance 日线），
  分段取自同目录 `reference_protocol.json`。
- 只运行当前默认配置（`config/params.yaml`，不做任何覆盖），分段 `train60` 与 `validation20`，
  期末按真实成本强制平仓（`forced=True`），与 SR P0/P1 研究一致。**禁止 `final20`**，脚本拒绝。
- **到期平仓**：`trades.csv` 中 `exit_reason == "MaxHoldingPeriod"` 的成交。
- **立即买回**：同一标的、`strategy_id == "TrendBreakout"` 的买入成交，成交时间在到期平仓成交之后
  K 个自然日以内（日线即 K 根 bar）。主口径 K = 3，另报 K = 1、5。每笔到期平仓最多配对一笔买回（最早的一笔）。
- 每一对记录：
  - **往返成本** = 到期卖出与买回两笔成交的 `costs.modeled_total` 之和（手续费 + 滑点 + 冲击）；
  - **价差** = (买回成交价 − 到期卖出成交价) × 买回数量。正值表示比一直持有多付的钱，负值表示买回更便宜；
  - **合计影响** = 往返成本 + 价差。

## 3. 预注册判定规则

记初始资金 C = 10,000。在 train60 **与** validation20 两段中都满足下面两条，判为“可忽略”：

1. 主口径（K = 3）立即买回次数 ≤ 3；
2. 主口径所有配对的合计影响之和 ≤ 0.25% × C（25 USDT）。

- **可忽略** → F-06 关闭，结论“维持现状”，阶段 C 不做。
- **不可忽略** → F-06 进入阶段 C 的候选清单（例如到期后的再入场冷却），需另行登记、
  一次只改一个维度，并建立新候选身份。本研究本身不改任何配置。

K = 1、5 与 K = 3 结论不同时只作说明，不改变判定。

## 4. 已知局限

- 默认 365 天到期很少触发；计数为 0 是合法结果。
- 价差只比较两笔成交价，不模拟“如果没有卖出”的后续路径；风控与健康机制的交互不归因。
- 两段共用同一冻结数据，只是事后计数，不构成样本外证据。
