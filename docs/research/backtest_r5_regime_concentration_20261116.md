# R5 行情切片与集中度（2026-11-16）

## 1. 问题

策略的收益来自哪里？是少数几笔交易、某一年、某一个标的，还是某一类行情？
H0：去掉最好的若干笔、最好的一年或最好的一个标的之后，收益仍为正，且在不同行情里不出现无法解释的反转。

## 2. 行情定义（冻结时写死，不得事后调整）

以 BTC 日线为市场代理，所有指标只用当日及之前数据（不得用全样本分位）：

| 行情 | 规则 |
| --- | --- |
| 牛 | BTC 收盘 > 200 日均线，且 200 日均线相对 20 日前上升 |
| 熊 | BTC 收盘 < 200 日均线，且 200 日均线相对 20 日前下降 |
| 震荡 | 其余 |
| 高波动（叠加标签，可与上面任一重合） | BTC 30 日已实现波动的**扩展窗口**分位 ≥ 80%（分位只用截至当日的历史计算） |

交易按**入场 bar 所在行情**归属；每日净值收益按**当日行情**归属。两种归属都报告。
行情天数过少（任一行情 < 60 个交易日）的行情，其结论标"证据不足"。

## 3. 切片维度

1. **行情切片**：上述四类。
2. **留一年**：逐年剔除，看剩余收益。
3. **留一标的**：逐标的剔除，看剩余收益；MATIC 单独列出并标注下架。
4. **集中度**：`concentration_stress(pnls, removals=(1, 3, 5, 10))`，即去掉盈利最大 1/3/5/10 笔。
5. **相关性与分散度**：全体标的 90 日滚动平均两两相关；组合的有效持仓数（1 / Σ 权重²）；
   在高相关时段（相关性 ≥ 滚动 80% 分位）的收益与最大回撤，对比低相关时段。
6. **状态泄漏**：对 `allowed_states` 有限制的策略（S1 只允许 TREND_UP，S3 SIDEWAYS，S4 VOLATILE），
   统计其交易中入场状态不属于允许状态的比例，期望为 0；非 0 记为缺陷线索而非研究结论。

## 4. 数据与分段

train60 与 validation20 合并后各自切片，并分别给出两段的数字；final20 禁止读取。
本研究只做切片，不按切片的结果挑选子集，也不据此修改策略。

## 5. 指标

每个切片：交易数、净收益、`ratio`、胜率、平均盈亏比、最大回撤、该切片对总净收益的贡献占比。

## 6. 预注册判定规则（草案阈值）

对象 X **通过**，当且仅当两段都满足：

1. 去掉盈利最大 5 笔后净平仓盈亏 > 0（`top5` 规则，沿用 SR 系列）；
2. 去掉盈利最大的一个日历年后，剩余净收益 > 0；
3. 去掉贡献最大的一个标的后，剩余净收益 > 0；
4. 没有任何单个标的贡献超过总盈利的 50%；
5. **行情一致性**：对无状态限制的对象（S2），在"牛/熊/震荡"三类中至少 2 类净收益 ≥ 0，
   且最差一类的最大回撤不超过全样本最大回撤的 1.25 倍；
   对有状态限制的对象，只评价"允许状态内"的行情，另要求状态泄漏率 = 0；
6. 高相关时段的最大回撤不超过低相关时段的 2 倍；
7. 样本量：参与判定的每个切片至少 10 笔交易；不足者仅报告，不参与 5 与 6。

不满足 1–4 任一：**未通过**，结果标出集中来源（哪一年、哪一个标的、哪几笔）。
不满足 7 导致 5/6 无法评价：**证据不足**，但 1–4 仍单独出结论。

## 9. 已知局限

- **幸存者偏差**：标的集合是后见之明留下的，其中只有 MATIC 是下架例外；留一标的与行情切片都不能消除这一偏差，
  结论只能作"在这批标的上"的描述。
- BTC 作市场代理在山寨币周期里并不总是同步，行情标签与单个标的的状态可能不一致。
- 行情样本较短（日线几年），各行情的有效独立周期很少，只能作定性判断。
- 去掉最好年份/标的之后的净收益是描述，不是对未来集中度的预测。
