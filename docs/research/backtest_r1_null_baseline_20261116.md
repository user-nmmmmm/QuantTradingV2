# R1 零模型与被动基线（2026-11-16）

> 状态：**草案，未冻结，无结果**。共同约束见[总纲](backtest_research_program_20261116.md)。
> 计划脚本：`scripts/run_backtest_r1_null_baseline.py`（本批不含）。

## 1. 问题

策略的收益有多少是"信号"，有多少只是"在这个行情里持有风险资产"？
H0：策略的业绩与同样结构（交易数、持仓期、方向、仓位规则）但信号无信息的策略没有区别。
H1：策略业绩显著优于 H0 的分布。

## 2. 被比较对象

| 类别 | 对象 |
| --- | --- |
| 被动 | 现金；BTC 买入持有；等权再平衡（每月，按当日已上市且有数据的标的） |
| 简单规则 | E0：普通 20 日突破（无状态机、无 OBV、无止损层，见 `current_strategy_protocol.json` 消融矩阵） |
| 策略 | S1 `TrendBreakout` 默认；S2 `TrendPortfolioV3` 默认；S3、S4 仅作零模型比较 |

所有对象走同一引擎、同一成本、同一 `initial_capital`，期末按引擎的 terminal policy 强平。

## 3. 零模型（两类，主次明确）

**主零模型：循环平移（circular shift）。** 把策略在每个标的上的信号序列整体循环平移一个随机偏移量
（偏移 ≥ 30 根，且不使平移后的信号落在预热期之前），保留信号的自相关与交易频率，破坏信号与未来收益的对应。
每个对象生成 N = 1000 条。

**次零模型：同结构随机入场。** 保持每个标的的交易笔数、持仓期的经验分布、方向、仓位规则，
入场日在该标的"策略被允许交易"的 bar 中均匀抽取：
- *无条件*：所有已上市 bar；
- *行情匹配*：只在策略 `allowed_states` 对应状态的 bar（S1 为 TREND_UP），排除"只是挑了好行情"的优势。
N = 1000。次零模型只报告，不作门槛，用来说明主零模型的结论是否被入场分布的选择所左右。

零模型策略类写在研究脚本里，不进入 `strategies/`。

## 4. 数据与分段

train60 与 validation20，各自独立运行；零模型的平移与抽样只在各段内部进行，不跨段。final20 禁止读取。

## 5. 指标

主指标：`ratio = return_pct / max_drawdown_pct`。回撤为 0 的约定：`return_pct = 0` 时记 `ratio = 0`（现金就是这种情形，所以与现金比较等价于要求 `ratio > 0`）；`return_pct ≠ 0` 而回撤为 0 时 `ratio` 记为未定义，该对象该段判"证据不足"并在结果中单列。辅助：夏普、总收益、`top5`（去掉盈利最大 5 笔后的净平仓盈亏）、
平仓交易数、换手、平均仓位。置信区间用固定块长 5 的移动块自助法（与 `WalkForwardConfig` 默认一致），种子 42。

经验 p 值：`p = (1 + #{零模型 ratio ≥ 实际 ratio}) / (1 + N)`。

## 6. 预注册判定规则（草案阈值）

对象 X **通过**，当且仅当：

1. `accounting_ok` 为真；
2. train60 与 validation20 **两段**的主零模型 p 值都 ≤ 0.05（三个策略 S1–S4 之间用 Holm 校正，族内共 4 个检验）；
3. 两段的 `ratio` 都高于现金、BTC 买入持有、等权再平衡中**最好的一个**被动基线的 `ratio`（现金按第 5 节约定取 0）；
4. 两段的 `top5 > 0`；
5. 样本量：组合层平仓交易数 ≥ 30（每段）。

- 满足 5 但不满足 2–4：**未通过**。
- 不满足 5：**证据不足**，不报告 p 值以外的结论。
- 通过的对象才进入 R2、R3 的调参环节（见总纲第 5 节）。

## 7. 多重检验与尝试登记

本研究没有调参。全部运行（对象 × 零模型 × 分段）写入实验登记；计入累计尝试数的唯一候选只是 S1–S4 的默认配置，各计一次，零模型样本与被动基线不算候选。
次零模型与被动基线不进入 Holm 族。

## 9. 已知局限

- 平移零模型保留了信号的自相关，但把信号与"行情状态"的对应一并破坏；对 S1 这类依赖状态机的策略，
  主零模型偏严，次零模型的"行情匹配"版本用来对照。
- 30 个标的相关性高，标的间并不独立；p 值是组合层的，不是标的层的。
- 日线数据下 S3、S4 的交易数可能不足，按"证据不足"记录。
- 现有标的是后见之明留下的幸存者集合（MATIC 是少数下架例外），被动基线因此偏乐观；这使"优于被动基线"这一条偏严，结论偏保守。
