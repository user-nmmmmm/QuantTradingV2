# 收益改进复核 · 2026-10-04

完成130次真实账户回放：主引擎56次，现货研究账户74次。结论是**发现相对60日趋势的局部历史改善；原策略引擎未出现超过旧强对照的新方案，尚无足够证据认定稳定收益提升**。

## 比较口径

- BTC/USDT、ETH/USDT固定两资产，原始日线2020-01-01至2026-09-19，正式计分2021-01-01至2026-09-19；初始资金每账户10,000 USDT。
- 三个独立重置窗口为2021–2022、2023–2024、2025-01-01至2026-09-19。另外单独跑完整连续账户，资金、持仓及费用连续结转。全期收益没有由三个窗口拼接或挑选而来。
- 每个固定方案均跑基准成本和1.5倍成本；后者同步提高佣金、滑点、价差与冲击等相应参数。数据和方案在本轮结果产生前注册，旧数据已被看过，因此仍是历史复核。
- 主引擎沿用旧对照的账户和风险控制，含其研究用健康门槛设置；现货研究账户为现金支持、仅做多、目标总仓位上限90%。两个框架的敞口、退出及成本模型不同，收益不作横向排名。
- 现货信号取已收盘日线，次根日线成交，常规每7根交易一次；总仓位漂移超限时可提前减仓。手续费0.1%、基础滑点0.05%、全价差2基点、冲击系数0.10、成交量参与率上限1%。这些仍是研究假设，缺少真实成交校准。
- 现货期末持仓按市场价格计入净值；主引擎沿用期末平仓。表中收益均扣除对应模型费用，最大回撤以正数列示；全期累计收益不是年化收益。

## 年度选择：没有改善

初始2021年预设60日趋势；随后只用上一年、距新年35天前已成熟的净收益，至少250个观测，选择正Sharpe最高的20/60/120日趋势，否则持有现金。选择只影响之后的信号，切换沿用同一个账户和每7根交易一次的时间表，买卖费用实际入账。成本压力复用基准成本下的同一目标序列。

## 统计证据与边界

- 新组合相对60日趋势，历史日收益差的年化算术均值为1.34个百分点；20日分块重采样的95%区间为[-8.21, 11.36]个百分点。5、20、60日三种分块长度的区间都包含0。这个区间针对年化算术均值差，不是累计收益或未来盈利的区间。
- 局部9个非现金账户的Reality Check诊断p值约0.668–0.702，未呈现有力优势；PBO诊断值约81.43%，DSR的局部诊断值不作准入概率。全局旧搜索历史不完整，正式概率保留为空、准入保持false。
- PBO等分割只用于历史诊断：候选收益之间高度相关，年度选择又内含历史训练，不能把同一收益面板的分割当成嵌套训练或未见测试。
- 固定BTC/ETH资产范围不构成完整历史币池；历史发布时间、市值和退市证据仍不完整。日线成交量不是订单簿深度，研究盈利未证明真实容量。
- 原来已冻结的两个前瞻协议内容及正式配置hash均保持不变，opened_at仍为空；本轮没有新增真实订单，也没有把研究候选升为正式策略。2026-10-04协议仍等待未来数据和标签成熟。
