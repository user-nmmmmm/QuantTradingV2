# 网页监控

在仓库根目录运行：

```powershell
python -m dashboard.web
```

随后打开 <http://127.0.0.1:8765/>。页面每 15 秒读取一次 `reports/live_status.json`、`reports/live_alerts.jsonl` 和可选的 Phase 6 报告。页面只监听本机回环地址，只提供读取接口，不发送订单或更改交易状态。原有 `python -m dashboard` 命令行视图继续可用。

没有实盘快照时，页面会明确显示快照不可用，隐藏账户数值。仅预览页面设计时可运行：

```powershell
python -m dashboard.web --demo
```

演示模式会在标题旁显示「演示数据」标识，所有数值均为示例。使用其他端口可加 `--port 9000`；状态文件位置可用 `--status`、`--alerts`、`--phase6-report` 指定。

权益轨迹仅记录当前网页服务启动后观察到的不同时间快照，最多 120 个点，不作为历史账本。页面的资金分布按权益减现金估算非现金部分；现金与权益无法直接比较时不绘制比例。

页面将超过 5 分钟或没有可核验时区的状态快照标为过期，过期时账户开仓门控和运行检查显示为待确认。此阈值只用于页面提示，不修改交易引擎的风险控制。

右上角可随时切换浅色和深色模式。首次打开时跟随系统外观，手动选择后会保存在当前浏览器中；切换外观只影响显示，不改变监控数据或交易状态。图表、状态色和浏览器原生控件会一起切换。

## 可视化数据

- **市场 K 线**：读取 `data/binance/1d/*_USDT.csv`，可切换交易对和最近 60、120、240 根日线；鼠标移到图上显示所选 K 线的开高低收和成交量。页面显示最后一根 K 线的日期与距今天数。此缓存是历史行情，不代表实时交易所报价。
- **动态监控**：沿用状态接口的 15 秒刷新节奏，展示最近检查、快照时间和最近告警；仅记录当前页面会话实际观察到的快照、运行状态、账户开仓门控、持仓数量变化和新告警。重新打开页面会清空会话记录。演示模式不制造真实变化事件。
- **回测可视化**：从 `reports/<运行目录>/equity.csv` 读取历史权益，计算总收益、当前及最大回撤；有 `benchmark.csv` 时可勾选基准虚线作同轴对照，有 `trades.csv` 时显示成交记录行数。基准可能远高于策略，默认隐藏以保证策略曲线可读。报告下拉框只列出有权益文件的运行目录。图表和汇总会显示回测区间，不应视作当前账户业绩。

网页仍为只读。本地缓存或报告不存在时，对应区域会显示数据不可用，其余监控区域可继续使用。
