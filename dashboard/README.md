# Stillwater Quant 本地研究工作台

账户监控、网页回测、交易诊断、技术指标、数据检查、实验档案和 Walk-forward 研究共用一个本地页面。使用 Python HTTP、原生 JavaScript ES Modules 与 SVG，前端无需 npm 构建、CDN 或远程字体。

账户监控读取状态快照；网页回测和研究在独立子进程中运行，会保存本地报告、配置快照及实验记录，不向交易所提交订单。代码职责与接口见 [FRONTEND.md](FRONTEND.md)。

## 本地启动

在仓库根目录运行，脚本选择现有虚拟环境并打开浏览器：

```powershell
.\scripts\start_dashboard.ps1
```

或直接运行 Python：

```powershell
.\.venv\Scripts\python.exe -m dashboard.web --open
```

已激活虚拟环境时，Windows / Linux / macOS 均可使用 `python -m dashboard.web --open`。

打开 [本地主页](http://127.0.0.1:8765/) 或 [回测实验室](http://127.0.0.1:8765/#backtest)。只监听本机回环地址。终端 Ctrl+C 停止服务并清理活动回测子进程。原有 `python -m dashboard` 命令行监控保留。

首次使用先按[项目安装说明](../README.md#41-安装依赖)安装依赖。启动脚本优先使用 `.venv\Scripts\python.exe`，否则选择 `PATH` 中的 Python；脚本本身不创建环境或安装依赖。

```powershell
# 自定义端口，不打开浏览器
.\scripts\start_dashboard.ps1 -Port 9000 -NoBrowser
# 明确标识的演示账户快照
.\scripts\start_dashboard.ps1 -Demo
# 关闭网页回测与稳健性研究任务执行
.\scripts\start_dashboard.ps1 -NoBacktests
```

Python 网页入口的常用参数如下；完整列表可用 `python -m dashboard.web --help` 查看。

| 参数 | 用途 |
| --- | --- |
| `--status` / `--alerts` / `--phase6-report` | 指定监控快照、告警和可选的 Phase 6 报告 |
| `--data-dir` | 指定本地日线目录，包含 `*_USDT.csv`；默认 `data/binance/1d` |
| `--reports-dir` | 指定回测报告与 `.dashboard` 实验档案所在目录；默认 `reports` |
| `--port` / `--open` | 修改监听端口 / 启动后打开浏览器 |
| `--demo` | 仅替换监控快照；合成回测需在表单另选 |
| `--no-backtests` | 禁止提交网页回测与稳健性研究任务 |

## 七个工作区

| 工作区 | 内容 |
| --- | --- |
| 工作台总览 | 权益、现金、持仓、开仓门控、会话轨迹和资金分布 |
| 回测实验室 | 策略参数/预设、离线任务、日志、权益/回撤、月度、闭合交易诊断、执行成交分页 |
| 市场行情 | K线及SMA、EMA、RSI、MACD、Bollinger、ATR、ADX、Stochastic、OBV、ROC、CCI、Williams %R |
| 运行监控 | 控制条件、策略健康、异常原因、会话事件和告警 |
| 实验与对比 | 持久档案、搜索筛选、名称/标签/笔记/收藏、复制实验、2–4次回测对比 |
| 本地数据管理 | 覆盖日期、缺失、重复、乱序、非法OHLCV与共同可用区间 |
| 稳健性研究台 | 参数候选、滚动训练/验证/OOS测试、分窗结果、热力图和研究证据 |

首次主题跟随系统，手动选择保存在当前浏览器。桌面侧栏和手机导航使用同一组路由，支持前进/后退；图表可通过鼠标或键盘箭头、Home、End 阅读。

## 完成一次研究

1. 在“本地数据管理”检查行情；验证功能时可选择合成数据。
2. 打开“回测实验室”，设置标的、日期、资金，选择当前配置、趋势突破或均值回归策略。
3. 调整允许的研究参数，查看配置差异；常用选择可保存为个人预设。
4. 提交任务。在本机子进程计算，切换工作区或刷新浏览器不会中断任务。
5. 查看收益/回撤、月度、闭合交易、费用、退出原因和有来源的诊断漏斗。
6. 在“实验与对比”保存笔记、标签、收藏，选择2–4个结果对比，或复制参数建立新实验。

标的下限由当前策略健康配置决定，最多4个。单次回测日期相差30–1096天；资金100–1,000,000,000 USDT，滑点0–100bps，1bps=0.01%。提交时逐日检查覆盖、缺口、重复、乱序和非法OHLCV。检查不自动下载或修改原始数据。

网页研究参数不修改基础 `config/params.yaml`；每次任务创建独立配置快照与 SHA-256，worker 核验后执行现有引擎。单次回测固定日线和 `compact` 报告。合成结果始终保留功能验证来源标签。

## 持久档案、配置和重启

以下路径基于默认 `reports` 目录；使用 `--reports-dir` 时相对于所选报告目录保存。

| 产物 | 默认位置 | 内容 |
| --- | --- | --- |
| 实验档案 | `reports/.dashboard/experiments.sqlite3` | 任务记录、笔记、标签、收藏和预设 |
| 提交时的配置 | `reports/.dashboard/configs/<id>.yaml` | 应用研究参数后的独立配置快照 |
| 普通回测结果 | `reports/web_<UTC时间>_<标识>/` | 实际报告、`dashboard_job.json` 与 `config.snapshot.yaml` |
| 稳健性研究结果 | `reports/research_<UTC时间>_<标识>/` | 网页结果、Walk-forward 明细、数据副本与证据登记 |

来源标签读取持久元数据，重启后仍能区分合成/本地行情。

服务内存保存最近30个任务，实验档案可分页查询更早记录。日志最多160行/任务、2,048字符/行。普通回测与稳健性共用一个执行槽，一次一个活动任务，默认20分钟超时。

正常退出清理活动子进程。重启将遗留运行记录标记 interrupted，不自动续跑；已完成报告、参数、笔记和预设保留。只有成功发布的网页任务才出现在成功报告目录。

配置快照记录当次配置，普通compact并不冻结全部代码和数据。“复制参数再跑”创建新实验，不等同于完整不可变环境下的严格重放。

## 结果口径

- 监控默认读取 reports/live_status.json、live_alerts.jsonl 和可选Phase6报告。缺失或过期快照明确显示不可用，不代入账户数值。会话轨迹最多120点，不是历史账本。
- 总收益和回撤来自有效权益；CAGR使用实际经过时间与365.25天/年。短区间年化可能放大结果。
- 月度连接前一个有观测月份的末值，首月可能不完整、缺失月份不补零。基准须匹配首尾才计算收益差。
- 执行成交、闭合往返交易、入场信号链属于不同总体。正收益周期占比不是交易胜率。
- 胜率、profit factor和期望盈亏基于闭合交易；无亏损样本时profit factor未知，不生成无穷大。样本不足保留状态。
- MAE/MFE使用记录字段原有单位；费用不重复扣减已在填单价中体现的滑点。
- Sharpe等风险指标仅展示引擎已保存的事实、状态与样本；未保存的Sortino、Calmar、年化波动率显示未知。
- 漏斗“数据→预热→信号→路由→风险→执行”只投影明确证据。门控/抑制计数有来源和范围，缺失不等于零，静默权益不能证明原因。
- 技术指标未预热时为“—”。使用完整受限历史计算后截取显示，不补缺失行情；周期按有效观测计数。
- 对比把各自初始权益归一化为100，按日历时间绘制。来源、标的、费用和区间差异会提示，显示采样不改变统计样本。

## 稳健性研究

使用真实引擎执行趋势突破参数网格：**3–6个候选、最多4个评估窗口**，与普通回测共享任务、日志和取消机制。训练30–180根日线、验证/测试各10–90根、purge1–30根，另需足够预热历史。

每窗只按验证期收益或Sharpe选参数，测试用于样本外评价；验证值全不可用则跳过。OOS曲线仅复合实际窗口收益并显示窗口边界，不把间隙补成未观测的日收益。热力图用于诊断，不依据测试收益重新选优。

reports/research_<UTC时间>_<标识>/ 保存网页result.json、完整walk_forward.json、配置快照、实际数据副本与evidence登记/尝试文件。这是回顾性滚动研究，不声明为独立未触碰留出集验证。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 账户状态不可用 | 核对路径和快照日期；离线研究仍可用，监控预览可用--demo。 |
| 行情缺失或范围不通过 | 核对CSV命名、列、日期和质量表；选择共同干净区间。 |
| 共同覆盖仍有缺口 | common_range仅为边界交集，结合complete；common_usable_range才是最长共同连续干净区间。 |
| 无成交诊断出现未知 | 对应阶段没有记录，不从零闭合交易反推信号或阻断原因。 |
| 回测或研究失败 | 查看任务日志、依赖、标的下限、数据范围与预热预算。 |
| 重启后为interrupted | 原任务没有续跑，检查保留记录后创建新的实验。 |
| 已有活动任务 | 普通回测与稳健性共享执行槽，等待完成或取消。 |
| 报告未出现在目录 | 确认成功状态；外部CLI需要compact/full等保留权益CSV的报告模式。 |
| 文件太大 | CSV每份16MiB；权益/基准/行情20,000行，执行/闭合交易100,000行。质量请求最多32标的、合计64MiB。 |
| 改动未显示 | 刷新页面触发ETag重验证，无前端构建步骤。 |
| 重启后令牌失效 | 刷新记录或页面获取会话令牌，先核对现有任务再重试。 |
